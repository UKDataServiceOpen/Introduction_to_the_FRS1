# Introduction_to_the_FRS1
This repository contains the Quarto source files of the practical exercises for the Getting started with the Family Resources Survey (FRS) UKDS Data Skills Module.

The FRS focuses on household income, benefits, and living standards in the UK. It is the main income sources for earnings, state benefits, tax credits and pensions. It provides information on housing costs, savings and material deprivation to assess financial wellbeing. Also, the FRS links income data with demographics, including household composition, disability status, and childcare that provides broad understanding of financial circumstances across different population groups.
